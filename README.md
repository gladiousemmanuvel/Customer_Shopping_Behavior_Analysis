# 🛍️ Customer Shopping Behavior & Demographics Analytics Dashboard

## 📝 Project Overview
This project explores retail customer demographics, purchasing behavior, item preferences, and spending patterns. Using the **Customer Shopping Behavior** raw dataset, Python for exploratory data analysis, MySQL for storing processed records, and Power BI for interactive visualization, this dashboard provides key consumer insights and customer segmentation trends.

## 🛠️ Tools & Technologies Used
* **Dataset:** Customer Shopping Behavior Dataset (`customer_shopping_behavior` raw data)
* **Programming Language:** Python (Pandas, Seaborn, Matplotlib)
* **Database & Querying:** MySQL (`cleaned_customer_data`)
* **Data Visualization:** Power BI (`Customer_Behavior_Dashboard`)
* **Development Environment:** Jupyter Notebook
